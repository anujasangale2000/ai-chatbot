# AI Chatbot 🤖

An interactive AI chatbot built with Streamlit and Ollama. It is just a simple chatbot which works in your system. 

## Features
- Real-time chat responses using Llama2 model
- Simple UI with smooth animations
- Chat history saved during session
- Runs locally (no API costs)

## Setup
1. Install Ollama: https://ollama.ai/
2. Pull llama2: `ollama pull llama2`
3. Install requirements: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`

## Technologies
- Python
- Streamlit
- Ollama
- Llama2 LLM
